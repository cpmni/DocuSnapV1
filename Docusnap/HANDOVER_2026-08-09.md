## WHAT SHIPPED, AND THE ONE THING EACH IS FOR

1. **`TEACH_ANGLE_COMPOSE_SCAN`** (`3fad281`) — the biggest win. A taught box carries the teach
   sample's tilt; the document has its own. At 1.6° a 0.16-wide box's centre moves ~0.010
   page-height — about ¾ of a text line — enough to shear a 2-row box onto the caption or address
   row. Measures the page tilt NON-DESTRUCTIVELY and composes the box by (θ_teach − θ_scan). **No
   pixel is rotated**, so the page, ocr_text, page-0 geometry, logo phash and every learning write
   stay in ONE frame. customer 52 wrong → 2, date 21 → 0.
2. **`TEMPLATE_FIXED_ISSUER_REPAIR`** (`d03b691`) — 42 of 135 documents read something other than
   the template's curated issuer: 15 an OCR garble, 27 not a company name at all. The app already
   printed the answer and asked the operator to confirm it. Two new DECLINE branches: a similarity
   floor (0.75) instead of a 1-edit budget, and a lexicon-free metadata test (a company name carries
   no printed date and no 4+ digit run). issuer 49 wrong → 19.
3. **Three teach-side gates** (`4e5c21c`) — a taught box committing its own caption as the
   reference; one code captured into three fields; and the silent one, a type you create losing the
   election to a built-in so the template binds to a slug its siblings can never detect as.
4. **Chris's findings 1/2/3/5** (`119f28a`) — filing-value sanity gates (26 true positives against 2
   false on 200 docs, and they surfaced 13 delivery numbers filed as `OED46699` where the page
   prints `OED/46699`); "Ready to file" instead of a false "Filed"; sender names no longer collapse
   to one character; and a "Not right? Type it:" box on every teach confirm step.
5. **SFDEV "All boxes"** (`8ff21ab`) — draws every winning field's crop region with its detection
   note. This is what found the stale-anchor and caption-read classes; use it first when a value
   looks wrong.

## WHAT WAS OVERTURNED — read this before revisiting deskew

The owner observed that values wrong on import come back correct after "Straighten + Reprocess".
Measured: adding `--deskew-pages` to import healed 213 of 1127 cells, ZERO lanes down, customer and
date to 100%. **I recommended it. Oracle ruled WRONG LAYER and was right.**

- `gen_customer_test.py:675` tilts every page by at most **1.6°** — entirely inside Tesseract's ~2°
  self-tolerance, inside `DESKEW_RAW_CROP_MAX_ANGLE` (2.0), and inside the band where this project's
  own doc-561 probe measured deskew making a REAL scan WORSE.
- The corpus adds noise AFTER rotating, so it **cannot contain the harm case** by construction.
- Both arms pinned `known_doc_slug` + `known_template_id`, so identification was held constant — a
  reprocess-shaped measurement of an import-path change.
- **`realdoc_regression.js` cannot gate this**: `:149` passes a manifest for every document, so it
  structurally cannot exercise the import-only identification path. A green run would have
  manufactured false confidence.
- **The one-command experiment that settled it:** re-run at a 2.0° floor → the entire heal VANISHED,
  0 of 1127 cells moved. The whole gain came from the harmful band.

`deskew_on_import` remains wired, DEFAULT OFF, with the ruling recorded against it. Its Settings copy
no longer claims "made nothing worse" — that was a property of one synthetic corpus.
