### Headline (verified/adjudicated severities)

keys-outside-docroot are all solid. Real items to action:
- **SEC-01 HIGH (only remote one):** admin console has no lockout/rate-limit + 2FA off by default → weak
  password brute-forceable → mint unlimited licenses.
- **SEC-02 MEDIUM\*:** IONOS signing key has NO deny backstop — safe only if the docroot points exactly at
  `public/`. **Verify: GET `https://<domain>/keys/ed25519_k1_sodium_seed.b64` + `/keys/admin_password.hash`
  must be 403/404** (else rotate). Add `keys/.htaccess` "Require all denied".
- **SEC-03 MEDIUM:** `/v1` document read endpoints miss role/status authz (read-only client reads
  uncommitted/deleted docs by id).
- **SEC-04 MEDIUM:** core↔client first-contact is TOFU + the pairing-code gate is dead code (only matters if
  `/v1` is LAN-exposed; off by default).
- **SEC-05 MEDIUM:** offline trial extension via DB snapshot + clock rollback.
- Client-side licensing tamper (config-key swap / asar patch / fingerprint spoof) = **LOW** — inherent to any
  offline gate, revenue-only. The crown jewel is the **server signing key**, not the client gate.
