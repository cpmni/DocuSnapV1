### `09685d9` — feat(anchor): crosscheck-outlier reconcile
**Root cause.** `anchor.py`'s authoritative-crop cross-check (`extract_with_anchors`, ~:852) fires on
`method=="anchor_crop" and (_is_ref_like_key OR date)`, does a FRESH full-page locate-OCR
(`_locate_for_relocation` → `tm._locate_anchor`, a SEPARATE OCR from the raw `ocr_text`), and on
`_reads_disagree` ALONE flips the winner to that read (`anchor_crop_crosscheck`, cap 70 + flag), which
wins Tier-A. The fresh locate can be the garbler → the correct crop+keyword+mapping value is discarded.
The existing engine seam **E2** (`_crosscheck_keyword_corroborated`, engine.py:~4193) only reconciles
the OPPOSITE direction (keyword==flip, the City-Office crop-mangled class).

**Fix (post-merge, gary's layer — NOT in-crosscheck).** New pass
`engine._reconcile_crosscheck_outlier` (just before G1, ~:5876), gated `CROSSCHECK_OUTLIER_RECONCILE`
default OFF. New predicate `_crosscheck_corroborated_alternative(winner, cands, ocr_text, is_date)`:
fires only when the flip is UNcorroborated (`not _fallthrough_critical_corroborated`) and returns a
DISTINCT alternative agreed by ≥2 independent families (`_crosscheck_witness_bucket`) with ≥1
crop-family leg AND `_page_presence_corroborated`. On hit → re-base to
`{value, method:"anchor_inline", confidence:_CROSSCHECK_CORROB_CONF(90)}` + drop
`validation_note`/`was_corrected`/`corrected_to` (mirrors E2).

**Oracle conditions (BOTH met):**
- **C1** — the crosscheck OVERWRITES value/method in place, so the ledger's `2_anchor` entry becomes
  the post-flip garble; a mapping-less ⊕-anchor-only doc would then have only 1 witness for the truth
  and NOT heal (a document fix). So `anchor.py` now stashes the pre-flip crop read as
  `_crosscheck_original` (GATED — only when the switch is on), consumed + popped by the pass as an
  independent crop-family witness. Pinned "load-bearing": without it, keyword alone → None.
- **C2** — `_method_family` folds every `anchor*` into one bucket, so bare `'anchor'` /
  `anchor_registration` would falsely count as independent. New `_crosscheck_witness_bucket` is finer:
  excludes `anchor_registration`/bare `anchor`/`anchor_crop_crosscheck`, requires ≥1 crop-family leg,
  page-presence a separate AND. So a silent drop-flag never rests on two correlated full-page reads.
