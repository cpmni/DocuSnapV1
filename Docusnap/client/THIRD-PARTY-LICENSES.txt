ScanFinder Search Client — THIRD-PARTY SOFTWARE NOTICES AND LICENSES
================================================================================

The ScanFinder Search Client is a thin, read-only desktop client that connects
to the core ScanFinder app's TLS /v1 API. It bundles only the components below.
All are free for commercial use; none impose copyleft obligations on the
client's own source. The client carries no Python/OCR stack and does not bundle
any font files (it uses the operating system's fonts).

This file satisfies the attribution requirements of the licenses below.
