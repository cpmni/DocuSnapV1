## 6. Traps hit this session (durable)
- **The Bash tool has NO node/npm/coreutils on PATH** — use PowerShell for `node`/`npm`, the Write tool (not heredocs) for
  scripts, dedicated Read/Grep/Glob for files.
- **Electron-as-Node prints nothing through the PowerShell tool** unless wrapped: `cmd /c ".\node_modules\electron\dist\electron.exe <x>.js > out.txt 2>&1"`, then Read the file.
- **`Stop-Process -Name electron` kills the LIVE app too** — I did this by accident once. Kill a sandbox by its specific PID.
  The auto-mode classifier now blocks broad process kills (correctly) — a full app restart is the OWNER's action.
- **A running dev app started before a commit does NOT have that commit's MAIN-PROCESS code** (handler env-bridges,
  main.js) — a full restart is required; renderer files reload on window reopen. (This bit the switch flip: the app was
  started 22 min before `5430bed`, so the flip needed a relaunch.)
- **The realdoc gate DB must be a `db.backup()` copy** (never a file copy), run at **`OCR_RENDER_DPI=200`** (the harness
  defaults to 300; the product reads at 200 — the confusable class only reproduces at 200). `RR_APP_ENV=1` only mirrors 3
  env groups (auto-title/anchor-crop/reconcile), NOT the arc flags — set those in the shell; `env: {...process.env,...appEnv}`
  so appEnv wins, but it lacks the arc flags so the shell flags survive. **The RR_CONSENSUS `ref`/`date` dump fields are
  OBJECTS `{val,conf,note,correct}`, not strings — diff on `.val`/`.correct` (I compared `[object Object]` once).**
- `git commit -F <file>` only — a multi-line PowerShell here-string in `git commit -m` breaks (message parsed as pathspecs).
- Literal control chars in a Python/JS source regex get mangled by the editor — build with `new RegExp('[\\u0000-…]')` /
  explicit `\x` ranges, not a `/[…]/` literal with real control bytes.
