Keyword Label Overrides

Teach the keyword stage extra words to look for on the page for a field on a document type, so it's detected immediately on import without per-document teaching. For example, if a worksheet prints “Serial No.” next to the value you want in the Reference field, add it here once and every future worksheet picks it up.

On reprocessing, Scan Finder looks for your words first, then falls back to its built-in words if yours aren't on the page (your built-in words are kept as a fallback, not removed). This applies to all documents of that type, not just the one on screen. A field you've taught with a drawn anchor still wins over these words. Overrides are specific to this installation — never shared or packaged.

Backup & Restore

Export your configuration — document types, fields, templates & mappings, file-naming, folders, and learned data (anchors, hints, corrections, logos) — to a single encrypted file, then restore it after reinstalling. The file does not contain your documents, users, or login details. Keep the password safe: without it the backup cannot be opened.

Restore overwrites your current document types, templates and learned data with the backup's; app settings are merged. This cannot be undone — export a backup first if unsure.

Diagnostic Logging

Writes a detailed per-document diagnostic log (every extraction stage, anchor crop coordinates, the values read, and the decisions made) to a file, for troubleshooting why fields are/aren't captured. Off by default. ⚠ The file contains document field values and OCR text — treat it as sensitive as the documents themselves. Takes effect on the next processing / reprocess run.
