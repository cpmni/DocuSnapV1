Filename Pattern

Controls how committed documents are named when filed. Build a pattern from the tokens below — click one to insert it. Default: {docType}.{date}.{ref} (e.g. Invoice.15-12-2025.INV-2025-0142.pdf) — this is the format DocuSnap has always used, so leaving it as-is keeps existing behaviour unchanged.

Supported Tokens

Values are filled in from the confirmed document. Missing values are skipped and any leftover separators (like a stray "." or "-") are tidied up automatically.

Always Made Windows-Safe

Whatever pattern you choose, DocuSnap automatically makes the resulting filename safe for Windows before it's ever written to disk — this happens in the background for every committed document, not just here in the preview: characters Windows forbids (< > : " / \ | ? *) are removed, trailing spaces and periods are trimmed, names Windows reserves for devices (CON, PRN, NUL, COM1, …) are defused, and duplicate filenames still get -DUPLICATE / -DUPLICATE-2 suffixes as before. If sanitising ever leaves nothing usable, DocuSnap falls back to the default pattern automatically.
