Import & processing

These apply to every import — manual, watch-folder and background alike.

Auto-file 100%-confidence documents
Skip Review for documents read with full confidence — file them automatically after processing
Read values that wrap onto the next line
When a field is taught to wrap (e.g. an address whose first line ends “-”), read the line below and join them. Single-line values are unaffected.
Auto-rotate sideways or upside-down scans
Detects a page scanned in the wrong orientation and turns it upright — both for reading and in the filed PDF. Only acts on a confident result; pages it isn't sure about are left as-is.

How many documents ScanFinder may OCR/process at the same time. Higher values may be faster on powerful PCs but use more CPU and memory.
OCR engine
Full-page OCR engine
Governs full-page document text only — zone, teach and template field reads always use Tesseract. RapidOCR is beta and falls back to Tesseract automatically if it isn't available.
Document separation
Split multi-document PDFs automatically
When a single PDF contains several separate documents (e.g. a batch of one-page alerts), ScanFinder files each as its own document. Conservative — a normal multi-page invoice is never split, and each part goes to Review before filing.
Name checks
Flag odd company/customer names for review
When a Supplier or Customer name reads like a document heading, a reference/code, OCR garble, or a cut-off name, ScanFinder marks it for review instead of filing it silently. It only flags for a human to check — it never changes or deletes the value.

Keyword Label Overrides

Teach the keyword stage extra words to look for on the page for a field, so it's detected on import without per-document teaching.

How this works

For example, if a worksheet prints “Serial No.” next to the value you want in the Reference field, add it here once and every future worksheet picks it up.

On reprocessing, Scan Finder looks for your words first, then falls back to its built-in words if yours aren't on the page (built-in words are kept as a fallback, not removed). This applies to all documents of that type, not just the one on screen. A field you've taught with a drawn anchor still wins over these words. Overrides are specific to this installation — never shared or packaged.

Backup & Restore

Export your configuration to a single encrypted file, then restore it after reinstalling.

What's included & safety

Includes document types, fields, templates & mappings, file-naming, folders, and learned data (anchors, hints, corrections, logos). It does not contain your documents, users, or login details. Keep the password safe — without it the backup cannot be opened.

Restore overwrites your current document types, templates and learned data with the backup's; app settings are merged. This cannot be undone — export a backup first if unsure.
