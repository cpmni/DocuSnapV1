Teach a new document

Let's teach Scan Finder a new document

You'll show Scan Finder one example — say an invoice from a supplier you use often. For each detail you just draw a box around its value — Scan Finder finds the printed label beside it for you and shows you what it found. It looks for that label first, then reads the value beside it — so it still finds the value even when the next scan is shifted, scaled or a little crooked. Draw every detail you can find on the page, wherever it is printed — the footer counts. If something genuinely isn't on the page at all, you can type it instead. It takes a few minutes the first time, and you can change anything later.

1 Pick the document  →  2 Draw values & labels  →  3 Done

The boxes you draw are the exact ones Settings → Templates shows later. Nothing is saved until the very end — you can go back at any point.
