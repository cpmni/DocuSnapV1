Teach a new document

Let's teach Scan Finder a new document

You'll show Scan Finder one example — say an invoice from a supplier you use often. For each detail you draw a box around its value, then mark the printed label next to it. Scan Finder finds that label first, then reads the value beside it — so it still finds the value even when the next scan is shifted, scaled or a little crooked. Fields that are always the same (like the company name) can be set as a fixed value instead — no drawing needed. It takes a few minutes the first time, and you can change anything later.

1 Pick the document  →  2 Draw values & labels (or set fixed)  →  3 Done

The boxes you draw are the exact ones Settings → Templates shows later. Nothing is saved until the very end — you can go back at any point.
