Scan Finder — User Guide
User Guide

Use this page before your first batch, and whenever a new company's document turns up.

Teach your documents

Teaching is showing Scan Finder one example of a document so it knows what that company's paperwork looks like and where the important details sit. Teach one; it handles the rest from that company by itself.

Pick one good example

For each company you deal with often, choose one scan that is:

  • clean — not faint, marked or crumpled;
  • flat and straight — not skewed on the scanner;
  • typical — the layout you usually get from them.

Start with your five biggest senders. You don't have to teach everyone at once — teach a new one whenever it first appears.

The six steps

Click Teach (the buttons down the left). The wizard walks you through it:

  1. Welcome. A short explanation of what you're about to do.
  2. Choose the scan. Pick the example from your scans folder (folder B).
  3. Say what kind of document it is. Choose a type (Invoice, Delivery Note…) or create a new one if yours isn't listed. See Kinds of document.
  4. Point out each detail. For every detail it asks for, draw a box around the value on the page — the actual number, date or name. It reads back what it sees so you can check.
  5. Review. A list of every detail you pointed out. Change anything that looks off.
  6. Done. Scan Finder files this document straight away and remembers the layout for next time.

The printed label helps it find the value next time

When you box a value, look for the printed label beside it — “Invoice No:”, “Date:”, “Total:”. Box that label too if the wizard asks. The label is how Scan Finder finds that detail on the next document, even if it has moved a little.

No label? The company name at the top usually has none — box the name on its own.

Would rather type it? If a value is hard to box, you can type it instead. Boxing is better where you can, because it teaches where to look as well as what it says.

Crooked scans, several pages, and lists

  • Crooked scan? Use Straighten before you box anything, so the boxes line up.
  • More than one page? You can point out details on any page — move between pages as you teach.
  • A list of values (several serial numbers, several line items)? Point out one value and the printed label beside it (for example “Serial No”). Scan Finder then collects every value with that label on the page. See Fixing a detail for editing lists later.
Advanced: the Template Wizard

Most people never need it. The Template Wizard (the ⚓ on the Review tool rail) is a manual way to map a layout box by box. Teaching does the same thing more simply — reach for the wizard only if a layout is unusually awkward.

What's next

Taught your regular senders? Now import the rest of your scans. The ones you taught are already filed; the rest wait for a quick check.
