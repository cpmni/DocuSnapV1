Scan Finder — User Guide
User Guide

Use this page before your first batch, and whenever a document from a new company arrives.

Teach your documents

Teaching means showing Scan Finder a single example of a document so that it learns two things: which company the document comes from, and where each important detail sits on the page. Once you have taught one document from a company, Scan Finder can read and file the rest of that company's documents on its own. Teaching your regular suppliers first is the quickest way to get most of your filing done automatically.

Pick one good example

For each company you deal with regularly, choose one scan to teach from. A good example is:

  • clean — not faint, marked or crumpled;
  • flat and straight — sitting square on the scanner, not skewed;
  • typical — the layout you usually receive from that company.

Start with your five largest suppliers. You do not need to teach every company at once; you can teach a new one at any time, and the natural moment is when its first document appears in Review.

The six teaching steps

On the Home screen, open Teach from the buttons on the left. A wizard then guides you through the process one step at a time:

  1. Welcome. A short explanation of what you are about to do.
  2. Choose the scan. Select your chosen example from your in-tray folder (Folder B).
  3. Say what kind of document it is. Choose a type, such as Invoice or Delivery Note, or create a new type if the one you need is not listed. See Kinds of document for more on types and their details.
  4. Point out each detail. For every detail the wizard asks about, draw a box around the value on the page — the actual number, date or name. Scan Finder reads back what it sees inside the box, so you can confirm it has read it correctly before moving on.
  5. Review. The wizard shows a list of every detail you pointed out. Check it over and change anything that looks wrong.
  6. Done. Scan Finder files this document and remembers the layout, ready to apply it to the next document from the same company.

Scan Finder finds the printed label for you

You only draw a box around the value. When you do, Scan Finder automatically looks for the printed label beside it — for example “Invoice No:”, “Date:” or “Total:” — and reads it back so you can check it has found the right one. You do not need to draw a box around the label yourself.

The label matters because it is how Scan Finder locates the same detail on the next document, even when the layout shifts a little or the value has moved further down the page.

Some details have no label at all. The company name at the top of the page usually stands on its own; Scan Finder recognises it by the name itself, so you simply box the name.

If a value is difficult to box accurately, you can type it in instead, using Or type it instead. Drawing a box is the better choice where you can manage it, because it teaches Scan Finder where to look on the page as well as what the detail says.

Crooked scans, several pages, and lists of values

  • A crooked scan. Use Straighten before you draw any boxes, so that your boxes line up with the text.
  • A document with several pages. You can point out details on any page, and move between the pages as you teach.
  • A detail that appears several times — several serial numbers, or several line items, for instance. Point out just one of the values together with the printed label beside it, such as “Serial No”. Scan Finder then collects every value that carries that label on the page. See Fixing a detail for how to edit these lists later.
The Template Wizard is for advanced use only

Most people never need it. The Template Wizard (the ⚓ icon on the Review tool rail) is a manual way to map out a layout box by box. Teaching achieves the same result far more simply, so reach for the wizard only if a particular layout proves unusually awkward to teach.

What to do next

Once you have taught your regular suppliers, import the rest of your scans. The documents you taught are already filed; the remaining ones wait in Review for a quick check.
