User Guide

Use this page when you need a document back — the accountant rang, or you just want to check something was filed.

Find a document

Open Search from the Home screen and type anything you remember — a company, a reference, an amount, part of a date. Results appear as you type; no need to press Enter. Amounts ignore commas, so 1137 finds £1,137.00.

Narrowing it down

  • From / To dates, a total amount (equals, more than, less than), and a document type sit beside the search box.
  • Include not-yet-filed adds documents still waiting in Review — they show a Needs Review badge so you can tell them from filed ones.
  • If a document isn't showing up, it's usually still in Review — tick that box and there it is.

Working with the results

  • Click a row to preview it — scroll to zoom, drag to move around, turn pages.
  • Ctrl+click picks several; Shift+click selects a range — then act on them together.
  • Right-click a row for its menu — including Send back to Review on a filed document.

What you can do with a found document

The Document Actions panel under the preview:

  • Open File / Open in Explorer — the document itself, or the folder it lives in.
  • Print — your printer's own dialog; every print is recorded.
  • Send back to Review — for a correction. It stays filed until you re-confirm it, so nothing is ever "un-filed" by accident.
  • Edit in Review — jump straight to its details.
  • Stamp… / Send… — mark it PAID or pass it to a colleague; see Stamps, approvals and the Mailbox.
  • Delete — to the recycle bin, never straight to gone.

The recycle bin

Deleted documents wait in the Recycle bin (a button at the top of Search). From there:

  • Restore one, or Restore all — each goes back to where it was deleted from: the review queue, or its filed folder.
  • Delete permanently / Empty bin — the true delete, admin-only, and it says so before it acts.

How you know it worked: restore a document and it reappears in its old place, pages intact.
