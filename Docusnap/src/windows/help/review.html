Scan Finder — User Guide
User Guide

The Review Window

The Review window is where you check what Scan Finder read before it's filed. It's the screen you'll spend the most time in — and once you know the layout, each document only takes a few seconds.

The three areas

The window is split into three parts:

  • Left — the queue. The list of documents waiting for you, with Review and Deferred tabs.
  • Centre — the document preview. The actual scan, which you can zoom and pan.
  • Right — the fields. What Scan Finder pulled out, ready for you to check and correct.

Reviewing a document, step by step

  1. Select a document in the queue on the left.
  2. Glance at the preview in the centre to see the real scan.
  3. Check the fields on the right. If one looks wrong, click it and type the correct value.
  4. Make sure the Document type is correct — change it from the dropdown if needed.
  5. Click Confirm & File.

Editing a field

Click into any field and type to correct it. The numbers on the diagram match the points below.

  1. Field name — what the value is (here, the reference number).
  2. The value Scan Finder read — click it to edit.
  3. Confidence badge — green means it's sure; amber/red means it's worth a check.
  4. Pick from document (⊕) — click it, then draw a box around the value on the scan and Scan Finder reads it for you.
  5. Validation flag — if a value doesn't suit its field (for example, text that isn't a real date in a date field), the box is gently flagged so you can fix it before filing.
Two quick time-savers
  • Start typing in a text field (about 3 letters) and Scan Finder suggests values you've used before — pick one to fill it instantly.
  • In a date field, press “t” to drop in today's date.

What "confidence" means

Each field has a confidence — how sure Scan Finder is that it read the value correctly. A high score means it's probably right; a low score means it's worth a closer look.

What the badges and statuses mean

You'll see a few colours and labels around the queue and fields. Here's the quick reference:

The action buttons

  • Confirm & File — accept the values and save the tidy, filed copy.
  • Defer — set the document aside to deal with later (find it on the Deferred tab).
  • Skip — move on to the next document without filing this one.
  • Delete — remove a document you don't want (you'll be asked to confirm).
  • Reprocess — read the document again from scratch, for example after improving the scan.
  • File All Ready — file every queued document whose type and required fields are already complete, in one go. Documents that still need attention are left for you.
  • Prev / Next — step through the queue one document at a time.
"Confirm & File" is greyed out?

That's deliberate. Confirm stays disabled until the document type and all required fields (usually type, date and reference) are filled in. Complete them and the button turns on.

When a scan reads badly

Two tools help with awkward documents:

  • OCR Enhancement — re-reads a poor scan with stronger image clean-up, which often recovers faint or noisy text. Use it, then Reprocess.
  • Split PDF — splits a multi-page PDF into separate documents (by page range, every page, or every few pages) — handy when one file actually contains several documents.

Admins also have the Template Wizard here, which teaches Scan Finder where a field sits on a layout — see Templates & Learning.
