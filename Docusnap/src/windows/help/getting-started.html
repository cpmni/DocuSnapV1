User Guide

Getting Started

A quick tour of opening Scan Finder, signing in, and finding your way around the main screen.

Opening the app and signing in

  1. Open Scan Finder from your desktop or Start menu.
  2. If your copy asks you to sign in, enter your username and password and click Sign in.
  3. The first time the app is ever used, it will ask you to create an admin account — keep these details safe, as the admin can manage everyone else's access.

What you can do depends on your role:

  • Admin — everything, including Settings and teaching new layouts.
  • Edit — import, review and file documents.
  • Read only — search and view filed documents.

First-time setup

On a brand-new installation, a short setup wizard runs once to get you going. It asks for the things Scan Finder needs and then takes you to the main screen.

  1. Output folder — where your tidy, filed documents will be saved. This is the only required step; a sensible default is suggested and you can change it.
  2. Appearance — choose a light or dark theme (you can change this later in Settings).
  3. Performance — how fast to process and how many documents to handle at once. The defaults are fine for most computers.
Already set up?

Existing installations skip this wizard. An admin can run it again any time from Settings → General → Re-run setup.

The home screen

When you open Scan Finder you land on the home screen. It's where you start a run or jump to any other area.

The simplified diagram below labels the same areas.

  1. Begin Import — choose a folder of scans and bring them in for processing.
  2. Process Documents — start reading the selected folder. Stop safely halts a run in progress.
  3. Review Queue — opens the Review window; the badge shows how many documents are waiting for a check.
  4. Search — find documents you've already filed.
  5. Settings — document types, fields, folders and preferences (admin only).
  6. Teach a document — guide Scan Finder to learn a new layout (admin/edit).
  7. Fast / Smart badge — shows how thoroughly it reads; click it to change the mode.
  8. ? — turn on help mode (click ?, then click any control to see what it does), or open this guide.
  9. Progress log — while a run is going, live updates appear along the bottom. When it finishes you'll see “✓ Finished — N filed” with a View Results quick table and a Review your documents button.

Processing mode: Fast or Smart

The badge near the top shows how Scan Finder reads your documents. Click it to change the mode in Settings.

  • Fast — reads documents almost instantly. Great for familiar, good-quality scans.
  • Smart — the default. Takes a little longer and works harder on anything it's unsure about.

You can switch between them at any time; it only affects documents processed afterwards.
