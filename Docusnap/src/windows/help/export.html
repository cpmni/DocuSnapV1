User Guide

Use this page when the accountant wants a list, not the documents — month-end, VAT time, or a quick tally.

Export to a spreadsheet

Export pulls the details of your filed documents — who, when, reference, total — into one file you can open in Excel or hand to your bookkeeper. The documents themselves stay where they are; the export is a list about them.

How to run one

  1. Open it. Click Export in the buttons down the left of the Home screen (or the Export data card). It's there for admins.
  2. Choose what goes in. Tick the document types and the senders you want — or leave everything ticked. Then tick the columns: date, reference, total, and any detail you've set up.
  3. Narrow the dates if you like. There are two date ranges: Document date (the date printed on the document) and Date filed (when you confirmed it). Month-end usually wants Document date.
  4. Pick the format. CSV opens in Excel and imports into most bookkeeping software; Excel (.xlsx) is a ready workbook; JSON is for other software.
  5. Check the preview, then Export. The row count and sample update live, so you can see what you're getting before you save.

How you know it worked: the saved file opens in Excel with one row per document and the columns you ticked.

Worth knowing
  • Only confirmed documents are included unless you tick Include documents still in Review.
  • Exported dates follow your regional date format — set in Settings → Processing → Date format (region).
  • Nothing leaves this computer; the export is a file you save where you choose.
