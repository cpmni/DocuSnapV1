Scan Finder — User Guide
User Guide

The Search Client (other PCs)

The Search Client is a small app your colleagues can run on their own computers to search your filed documents — and, if they’re an admin or edit user, to review and file documents from the review queue — without installing the full Scan Finder.

Still on your network

The Search Client talks only to the PC running the main Scan Finder app, over your local network. Nothing is sent to the internet.

How it connects to the main PC

One PC runs the main Scan Finder app (the one that imports and files documents). Every Search Client connects to that PC. To set it up:

  1. On the main PC, open Settings → Search client access and turn it on. Note the address (the main PC's network address, e.g. 192.168.1.50) and the port (a number, 8765 by default).
  2. Still on the main PC, click Export connection profile. This saves a small file that holds the address, port and the security certificate.
  3. On the other PC, open the Search Client and choose Import connection profile (or type the address and port by hand and fetch the certificate when asked). The connection is encrypted, and the certificate makes sure the client is talking to your PC and not an impostor.
  4. Sign in with the username and password you were given. That's it — search away.
Good to know

The main PC needs to be switched on and running Scan Finder for clients to connect. If the main PC sleeps or closes the app, clients simply show “disconnected” and reconnect by themselves when it's back.

Letting clients through the firewall

For other PCs to reach the main PC, Windows Firewall on the main PC has to allow the port. You only do this once, on the main PC — the client PCs need no firewall changes (they make outgoing connections, which are allowed already).

To add the exception on the main PC:

  1. Click Start, type Windows Defender Firewall with Advanced Security and open it.
  2. Click Inbound Rules on the left, then New Rule… on the right.
  3. Choose Port → Next.
  4. Choose TCP, and in Specific local ports type your port (8765 unless you changed it) → Next.
  5. Choose Allow the connection → Next.
  6. Tick at least Private (your office network) → Next.
  7. Name it something like Scan Finder search client → Finish.
Use the same port number

The port in the firewall rule must match the one shown in Settings → Search client access. If a client can't connect, a missing or mismatched firewall rule is the most common cause — check this first.

How many people can connect

Your licence includes a number of seats. Each Search Client uses one seat while it's connected. When every seat is in use, the next person to open a client is told the seats are full — they can get in as soon as someone closes their client, or an administrator frees a seat. So the number of people who can use it at the same time is the number of seats on your licence.

There's no separate technical limit to worry about — it's simply your licence. Need more people on it at once? Add more seats.

When several people use it at once

Lots of people can search and open the same document at the same time — that's fine. Two things keep everyone safe from treading on each other:

  • Deleting is reversible. Deleting a document moves it to the Recycle bin rather than erasing it (the file is kept). So if someone deletes a document another person is looking at, nothing is lost — it can be restored from the Recycle bin. Only an administrator can permanently remove it.
  • Documents in an approval are locked. Once a document has been routed to someone for sign-off, it can't be changed or deleted until that approval is finished — so it can't be pulled out from under the person making the decision.

The person who deleted a document sees it disappear from their results; anyone still viewing it keeps what's already on their screen until they next search or refresh, where it's then gone (and recoverable from the Recycle bin).
