Troubleshooting & FAQ

Quick answers to the things people ask most. Each one is "what you're seeing → what to check → what to do".

Common questions

A field came out wrong or empty

  1. Open the document in the Review window.
  2. Click the field and type the correct value — or use the pick button to grab it from the scan.
  3. If the whole scan reads poorly, try OCR Enhancement and then Reprocess.

My document isn't showing up in Search

  1. Search only shows documents you've confirmed and filed.
  2. Check the Review queue — it's probably still there, waiting to be confirmed.
  3. Confirm it, and it will appear in Search.

The "Confirm & File" button is greyed out

  1. A required field is missing — usually the document type, date, or reference.
  2. Fill in anything highlighted as required.
  3. The button turns on as soon as everything required is present.

Processing is slow, or a scan won't read

  1. Large batches and faint or skewed scans naturally take longer.
  2. For a single bad scan, use OCR Enhancement in the Review window, then Reprocess.
  3. An admin can raise the number of threads in Settings to speed up big imports on a capable computer.

Where did my filed document go?

  1. It's in your output folder, grouped by company, year and month.
  2. The file is named Type.Date.Reference — for example Invoice.15-12-2025.INV-001.pdf.
  3. The easiest way to find it is Search, then "show in explorer".

One PDF actually contains several documents

  1. Open it in the Review window.
  2. Use Split PDF to break it into separate documents (by page range, every page, or every few pages).
  3. Review and file each one as normal.

Scan Finder keeps reading a layout wrong

  1. Confirm a few documents from that supplier accurately — it learns as you go.
  2. For a stubborn layout, use Teach a document to show it where each field sits.
Still stuck?

Use the ? help mode on the main window to learn what a specific control does, or revisit the relevant section of this guide. Remember — everything stays on this computer, so your documents are never lost to an upload or a connection problem.
