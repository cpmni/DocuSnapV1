Troubleshooting & FAQ

The one rule underneath every answer here: nothing in Scan Finder is final. A filed document can come back, a deleted one can be restored, and a wrong lesson can be unlearned.

Common questions

It filed under the wrong company

  1. If it filed itself: the Home screen's "filed by itself" figure (or the strip in Review) lists them — open the document and click Put back. It returns to Review and won't file itself again until you confirm it.
  2. If you filed it: find it in Search and click Send back to Review, fix the Document Issuer, and confirm.
  3. Keeps happening for the same sender? See When it keeps getting a sender wrong.

It filed something without asking me

  1. That's by design once a sender has earned it — after enough clean confirmations, that sender's documents file themselves, and the Home screen always shows how many.
  2. Click the figure to look them over; Put back returns any you want to check.
  3. Want it never to happen, or to happen less? The pass-mark slider and the clean-confirmations count are in Settings → Processing. Full story: When it files by itself.

A detail came out wrong or empty

  1. Open the document in Review, click the detail and type over it — or draw a box round the right value on the page.
  2. A brand-new sender fills in very little by itself — that's normal. Teach it once (Teach your documents) and its next documents arrive read.
  3. More ways to fix a stubborn one: Fixing a detail.

"N documents couldn't be read"

  1. The small note after an import means those files were held for retry — not filed, not lost.
  2. Click Details to see which files and why (usually a locked, damaged or password-protected PDF), fix the cause, then Try again.

I taught a sender but it still asks me

  1. Teaching fixes the reading; the trust to file alone is earned by clean confirmations. Freshly-taught documents arrive read but still wait for your OK the first few times — that's the design.
  2. Check the details are arriving filled. If one keeps coming out wrong from the taught spot, re-teach that one detail with a slightly bigger box.
  3. A document from before the lesson? Reprocess it — lessons apply from the re-read.

The "Confirm & File" button is greyed out

  1. Something required is missing — usually the document type, the date, or the reference.
  2. Fill in whatever is highlighted; the button wakes up as soon as everything required is there.

A value in a list is missing (serial numbers and the like)

  1. On a list detail, each value is its own little box. Click + One it missed and draw a box round the missed value on the page.
  2. That also teaches the printed caption, so future documents collect it themselves.

The scan is crooked or faint

  1. Straighten (above the page in Review) squares it up; Clean up a hard-to-read scan (the tool rail) re-reads a faint or noisy page.
  2. Then Reprocess. Still bad? Re-scan that page — a good scan beats any cleanup.

One PDF actually contains several documents

  1. Open it in Review and use Split PDF — by page range, one file per page, or every N pages. The parts return to Review as separate documents; note the original PDF is removed by the split (it says so before it acts).
  2. For future piles, print separator sheets (on the Import screen) and slot them between documents — the batch then splits itself.

My document isn't showing up in Search

  1. It's probably still in Review — tick Include not-yet-filed in Search, or confirm it in Review and search again.

A real company name got flagged

  1. That's the name check being careful with an unusual-looking name; it never changes the value.
  2. If the name is right, just confirm — that teaches it and the flag stops.

I deleted something by mistake

  1. Nothing deleted in the app skips the Recycle bin — open it in Search and Restore. It returns to wherever it was deleted from.

Processing is slow

  1. Big batches and faint or crooked scans take longer — that's mostly the reading itself.
  2. An admin can raise Documents processed at once in Settings → Processing on a capable computer, or drop the reading detail a notch.

How do I move to a new computer?

  1. Settings → Advanced → Backup & Restore: export the one password-protected setup file, copy your output folder like any other files, install on the new machine, restore. Detail: Backup & Restore.
Still stuck?

The ? help mode explains any single control (click ?, then click the control), and the guide's search box (press /) jumps to any topic. Everything stays on this computer — a connection problem can never lose a document.
