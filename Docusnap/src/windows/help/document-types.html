User Guide

Use this page when a kind of document — or one of its details — is missing from the app.

Kinds of document and their details

A document type is a kind of paperwork you file — an Invoice, a Delivery Note, a Worksheet. Every supplier's invoice looks different, but they're all still invoices: a small handful of types covers everything you receive. Each type carries the details to capture (the screen calls them Fields). Set both up in Settings → Document Types — an admin job; everyone else just sees the results.

The quickest way: add from the catalog

Add from catalog… offers ready-made types — Purchase Invoice, Sales Invoice, Credit Note, Delivery Note, Statement, Receipt, Remittance Advice, Quote — each arriving with sensible details already in place. Tick the ones you file. Adding one twice does nothing, and a catalog type can be removed later.

The three details every type has

Every type always carries three locked details (the 🔒):

  • Document Issuer — the company the document is from.
  • Date — the document's date.
  • Reference — its main number (invoice number, order number…).

These three drive the folder and file name, and everything Scan Finder learns about a sender — so they can't be deleted or switched off. The value on any one document is always yours to correct; correcting it is what teaches the app.

Your own details

Add anything you care about — a PO number, a VAT number, a serial list. Give it a name and pick its data type, so Scan Finder knows what a good value looks like:

The list in Settings is the full, current set. A detail can also be switched off for one sender's paperwork ("never on these documents") from Review.

Renaming a detail is safe

Prefer "Customer reference" to "Reference"? Rename it. The label is what you see; behaviour follows the detail's role, so nothing breaks.

How a document's type is recognised

Scan Finder reads the title printed at the top of the page and matches it to your types by name. If a sender prints something different — "Work Sheet" for your "Worksheet" — add the printed wording in the type editor's Also appears as box rather than renaming the type.

Worth knowing
  • Matching ignores capitals and spacing, but it's exact — "W-Sheet" only works as an added alias.
  • One sender, several kinds of document on the same letterhead? The title on the page is what tells them apart — make each type's name or alias match the print.
  • A brand-new type's first document or two may need a tidy-up; confirm them and Scan Finder learns the layout.
