Scan Finder — User Guide
User Guide

Use this page when you have a folder of scans to bring in.

Import a batch

The two folders

Keep them apart. Folder B holds fresh scans waiting to come in. Folder A is where Scan Finder files the tidy copies. You import from B; filed documents land in A.

Bring them in

Click Import, then choose folder B, then Process Documents. Scan Finder makes its own copy of each scan to read, so your originals are safe — they stay in folder B until you file them. A big pile takes a while; Stop halts it after the current file.

When it finishes, a results table lists what it found:

  • Ready to file — read cleanly; you can file it with one click.
  • Confirm to file — it wants you to check something first.
  • couldn't be read — the scan was too poor to read; open it in Review and straighten or re-scan it.

Click Review your documents to check them. What you taught earlier is already filled in.

A few things to know

  • What happens to a scan after you file it? Its original is moved out of folder B — into a “Processed” folder if you asked to keep originals (Settings → Files & filing), otherwise removed. The filed copy is the one in folder A.
  • Two documents in one PDF? Put a blank separator sheet between them, or use Split in Review to break the file up. Splitting replaces the original file, so keep a copy if you need one.
  • Same document twice? Scan Finder marks a duplicate rather than filing it twice.
  • Don't want to click Import each time? A watch folder (Settings → Files & filing) brings in anything dropped into a chosen folder automatically.
The first time will feel slow

Reading scans takes real work, and nothing files by itself until you've confirmed a few from each sender. It speeds up fast — by your second or third batch most documents come through marked Ready to file.
