User Guide

Set up the Search Client — step by step

This guide walks you through letting other PCs on your network search your filed documents using the small Search Client app. It's written to be as simple as possible — you only do the setup once, on the main PC. For background on what the Search Client is, see The Search Client (other PCs).

Two PCs, two roles

The main PC is the one running the full Scan Finder app (it imports and files documents). The other PCs run the lightweight Search Client. Everything below — turning on access, the certificate, the firewall — is done on the main PC. Nothing leaves your local network.

Step 1 — Turn on access & enter the address

On the main PC, open Settings → Search client access:

  1. Switch Allow search-client connections on.
  2. In the address box, enter how the other PCs should reach this one:
    • For other computers on your network, enter this PC's network (LAN) address — e.g. 192.168.1.50. (Not sure of it? See the FAQ below: “Which address do I enter?”.)
    • 127.0.0.1 means this PC only — useful for testing, but other PCs can't reach it.
  3. Leave the port as 8765 unless you have a reason to change it. (Remember the number — it must match the firewall rule in Step 4.)

Step 2 — The security certificate (made for you)

Here's the part people worry about — and it's the easiest. You don't create or manage any certificate files.

What happens automatically

The moment you turn access on with a network address entered, Scan Finder automatically creates a security certificate for that exact address. That certificate does two jobs: it encrypts the connection, and it lets each Search Client check it's really talking to your PC and not an impostor. If you later change the address or port, Scan Finder re-issues the certificate to match — again, with nothing for you to do.

You can see the certificate's status (and a short fingerprint — a unique code that identifies it) under Managed TLS certificate in the same panel. You'll use that fingerprint in Step 3 if you connect a client by hand.

You don't need to be a certificate expert

Re-issuing certificates, exporting them, or using your own are tucked under Advanced — most people never touch them. The automatic certificate is all you need.

Step 3 — Connect the other PC

On each other PC, open the Search Client and connect using one of these two ways:

  • The easy way — a connection profile. On the main PC, open Advanced under Search client access and click Export connection profile…. That saves one small file holding the address, port and certificate. Copy it to the other PC (USB stick, shared folder, email on your network) and choose Import connection profile in the Search Client. Done.
  • By hand. In the Search Client, type the main PC's address and port. The first time, it shows the certificate's fingerprint and asks you to confirm it — check it matches the fingerprint shown on the main PC, and accept. This proves the client reached the right PC.

Then sign in with the username and password you were given. That's the setup finished — from now on the client just reconnects on its own whenever the main PC is on.

Step 4 — Allow it through Windows Firewall

For other PCs to reach the main PC, Windows Firewall on the main PC has to allow the port. You do this once, on the main PC only — the client PCs need no firewall changes (their connections are outgoing, which Windows already allows).

  1. Click Start, type Windows Defender Firewall with Advanced Security, open it.
  2. Click Inbound Rules (left), then New Rule… (right).
  3. Choose Port → Next.
  4. Choose TCP, and under Specific local ports type your port (8765 unless you changed it) → Next.
  5. Choose Allow the connection → Next.
  6. Tick at least Private (your office/home network) → Next.
  7. Name it Scan Finder search client → Finish.
The port must match

The port in the firewall rule must be the same as the one in Settings → Search client access. A missing or mismatched firewall rule is the most common reason a client can't connect — check this first.

Connection problems — FAQ

The client says it can't connect.

Work through these in order:

  1. Is the main PC switched on and Scan Finder running (or running in the tray)? Clients can only reach a running main app.
  2. Is Allow search-client connections still on in Settings?
  3. Is the firewall rule in place on the main PC, with the same port (Step 4)?
  4. Are both PCs on the same network? A guest Wi-Fi or VPN can put them on different networks.
  5. Is the address the main PC's current LAN address (see below)?

It worked yesterday but not today.

The main PC's network address may have changed — many networks hand out addresses that can change after a restart. Two fixes: ask whoever manages your router to give the main PC a fixed (reserved) address, or simply re-export the connection profile and import it on the clients again.

It shows a certificate or security warning / “doesn't match”.

This normally means the certificate was re-issued — usually because the address or port changed. On the client, either import a fresh connection profile from the main PC, or re-confirm the fingerprint when prompted. Always check the fingerprint matches the one shown on the main PC.

Which address do I enter?

The main PC's LAN address. To find it: on the main PC press Windows key + R, type cmd, press Enter, type ipconfig and press Enter. Look for IPv4 Address (it usually starts 192.168. or 10.) — that's the number to enter. Avoid 127.0.0.1 for other PCs (that's local-only).

Do the other PCs need a firewall rule too?

No — only the main PC. The client PCs make outgoing connections, which Windows permits by default.

It says the seats are full.

Your licence includes a set number of seats, and each connected client uses one. When they're all in use, the next person waits until someone closes their client, or an administrator frees a seat under Client seats in Settings. See How many people can connect.

Can I test it on the main PC itself first?

Yes — set the address to 127.0.0.1 and run a Search Client on the same PC. That confirms the basics work before you involve the network. Switch the address back to the LAN address (and re-export the profile) when you're ready for other PCs.
