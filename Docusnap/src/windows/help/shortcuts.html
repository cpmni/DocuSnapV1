Keyboard shortcuts & handy gestures

You never need a keyboard shortcut — every action has a button. But once you're reviewing a lot of documents, a few keys make it much faster. Here's everything, no matter how small.

The big three (Review)
  • Ctrl + Enter — Confirm & File the document you're on.
  • Space — Mark Reviewed.
  • ↑ / ↓ — move to the previous / next document.

Learn just those three and reviewing becomes a rhythm: check, Ctrl+Enter, ↓, repeat.

Review window

KeyWhat it does
Ctrl + EnterConfirm & File the current document. Any half-typed field is applied first. (Ignored while a pop-up is open or Confirm is greyed out.)
SpaceMark Reviewed (when that button is showing). Doesn't fire while you're typing in a field.
↑ / ↓Previous / next document in the queue.
tIn a date field, drops in today's date.
↓ / ↑ then EnterIn a text field, moves through the suggestions (values you've used before) and picks one.
EscClose whatever's open — the expanded field editor, the learning-history panel, or Help mode.
Enter / EscWhen the Split PDF bar is open: run the split / cancel it.
Delete / BackspaceDelete the box you've selected in the Template Wizard (admin drawing tool).
Taking the guided tour?

On the "Confirm & File" step, Ctrl+Enter advances the tour just like the real action; Esc stops the tour at any time.

Search window

Search is type-ahead — just start typing in the search box and results update as you go (no need to press Enter). Selecting rows works like a file list:

ActionWhat it does
Click a rowPreview that document.
Ctrl + clickAdd / remove that row from a multi-selection.
Shift + clickSelect a whole range of rows.
Right-click a rowA menu with actions for that document (Delete, or Restore / Delete permanently in the Bin). Some options depend on your role.

Settings & Templates

KeyWhat it does
← ↑ ↓ →In the Template Manager, nudge the selected mapping box a tiny step. Hold Shift for a bigger step.
↑ / ↓Move through the document list in the Learning-review pane.
EnterRun the search in the Learning-review and Audit filter boxes.
Enter / EscConfirm / cancel a pop-up (adding a document type, naming a template group, and similar).

Handy mouse gestures

Some of the most useful actions are done with the mouse and aren't obvious at first:

GestureWhat it does
Scroll wheel over a previewZoom the document in / out (Review, Template Manager and the teaching tools).
Right-click-drag a previewPan the zoomed document around.
Left-drag a box on the scanWith a field armed (the ⊕ "pick from document" tool, or a teaching tool), draw a box round a value and Scan Finder reads it in.
Drag the queue dividerIn Review, drag the line between the file list and the document to make either wider. Your width is remembered.
Drag a home-screen card by its headerRe-arrange the cards on the home screen; the layout is saved.
Right-click a field in ReviewA small clean-up menu (for example, strip a leaked heading from a value). Admin / Edit users only.
Prefer buttons? That's fine.

Every shortcut here has a button or menu item too — shortcuts are just a faster way to do the same thing. And the ? Help mode (top of the window) lets you click any control to see what it does.
