Settings, tab by tab

Settings is for admins; if you don't see the button, your account doesn't have it. Nearly everything ships with a sensible default — this page is a map, not a to-do list.

The tabs

Everyday, at the top:

  • Files & filing — your folders (where scans come from, where filed documents go, the watch folder), whether originals are kept, and the naming builders. Detail: Where things go.
  • Document Types — the kinds of document and their details. Detail: Kinds of document.
  • Processing — how scans are read and when documents file themselves: the filing-by-itself pass mark, clean confirmations before a sender is trusted, auto-rotate, faint-small-print reading, straightening, barcode reading, date and number formats (region), document separation and separator sheets, printing on/off, name checks, and the Review confidence threshold. When a page here mentions "a setting", this tab is usually where it lives.
  • Appearance — the colour theme (light, dark and seasonal sets), which Home cards show, and whether closing the window minimises to the tray.

Administration, below the divider:

  • Templates — the advanced layout viewer. Use only when a layout keeps failing; everyday teaching lives in Teach.
  • Learning — a read-only browse of everything learned (the memory inventory), extra printed words for a detail (Keyword Label Overrides), and per-sender clean-up tools. Detail: When it keeps getting a sender wrong.
  • Learning Repair — send a wrongly-confirmed document back to Review so the learning rights itself. Same page as above.
  • Users & activity — accounts and roles, who may stamp, the stamp words, automatic document routing, recent account activity. Detail: Users, licence and safekeeping and Stamps and approvals.
  • Audit — the full searchable record of what's been done.
  • Licensing — trial/licence state, activation, client seats.
  • Search client — let other PCs on your network search; the guided setup lives here. Detail: Search from other PCs.
  • Advanced — Backup & Restore, diagnostic logging, the Terms, re-run setup.
Two habits that pay off
  • Numbers like the pass mark are sliders here, not fixed rules — when this guide says "sure enough to file by itself", the slider on the Processing tab is what defines "enough".
  • After a big setup change, take a backup (Advanced). One file, one password.

Where to find help

  • User Guide — this guide: the User Guide… item in your account menu, or the Help button at the top of the main window.
  • The "?" help mode — quick one-line explanations, below.
  • Troubleshooting & FAQ — what to do when something looks wrong.

The "?" help mode

  1. Click the ? at the top of the window — the pointer changes.
  2. Click any control — a button, a field, a badge.
  3. A short explanation pops up, and help mode switches itself off.
  4. Esc or a click away dismisses it.

It works on every screen that shows a ? button.
