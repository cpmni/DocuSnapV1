User Guide

Settings & Help

Settings let an admin tailor how Scan Finder works. Most people rarely need to change anything — but here are the settings you're most likely to touch, plus where to find help.

Admin only

Settings are available to admins. If you don't see the Settings button, your account doesn't have permission — ask whoever set up Scan Finder for you.

Settings you may need

  • Output folder — where your filed documents are saved. Change this if you want documents to go somewhere else.
  • Processed-scans folder — where originals are kept track of after processing.
  • Processing mode — Fast (instant) or Smart (the default, more thorough). Pick whichever suits your documents.
  • Performance / threads — how many documents to work on at once. More can speed up large imports on a capable computer; the default is a safe choice.
  • Document types & fields — turn document types on or off and add your own fields (for example a "PO number") to a type.
  • Templates — review the layouts Scan Finder has learned.
  • Activation — shows your licence status.
  • Re-run setup — opens the first-time setup wizard again.

Where to find help

Scan Finder has help built in, in three forms:

  • User Guide — this guide. Open it from the User Guide button, the card on the home screen, or the Help button at the top of the main window.
  • Quick explanations — the ? help mode, described below.
  • Troubleshooting — common problems and fixes are on the Troubleshooting & FAQ page.

The "?" help mode

This is the quickest way to learn what a button does without leaving what you're doing.

  1. Click the ? button at the top of the window. The pointer changes to show help mode is on.
  2. Click any control — a button, a field, a badge.
  3. A short explanation pops up. Help mode then switches off automatically.
  4. Press Esc or click away to dismiss the explanation.

Help mode is available on the main window and other screens that show a ? button.
