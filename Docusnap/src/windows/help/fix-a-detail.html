Scan Finder — User Guide
User Guide

Use this page when a detail Scan Finder read is wrong or missing.

Fixing a detail

Type over it

The quickest fix: click the detail on the right and type the correct value. When you file the document, Scan Finder remembers your correction for that sender, so it gets it right next time.

Point at the right value on the page

If it read the wrong part of the page, you can show it where to look instead. Click the ⊕ beside the detail, then draw a box round the correct value on the scan. It reads what's in the box and, from then on, looks there for that sender.

Dates and amounts

Type a date the way it's written on the page — Scan Finder tidies it into your regional format. (You set day-first, month-first or year-first in Settings → Processing → Date format.) If a date won't file, it's usually because it can't be made sense of; retype it clearly. Amounts work the same way — the number is stored plainly whatever grouping your region uses.

“Use” and “Keep”

Sometimes a detail shows two buttons — Use “…” and Keep “…”. That happens when the value it read and another value it found on the page disagree. Use takes the one from the page; Keep stays with what's shown. Pick whichever matches the document in front of you.

A detail that holds several values

Some details are a list — several serial numbers, several line items. Each value shows as its own little box (a pill):

  • Click a pill to edit that value.
  • Click its ✕ to remove it; a ↻ puts it back if you change your mind.
  • + One it missed lets you point out a value it didn't pick up.
  • Edit as text shows the whole list in one box for a quick tidy.

Editing a pill changes this document only — a list won't overwrite what it learned for the sender.

This document only, or learn it?

When you correct the company, date or reference, Scan Finder learns it for that sender and uses it next time. If correcting a reference also fixes the same misread on other documents from that sender, it offers to correct those too — and an Undo if that wasn't what you meant. Editing a list value, by contrast, only ever changes the document in front of you.

Getting it wrong doesn't cost you

If a correction taught the wrong thing, you can un-teach it later — see Troubleshooting.
