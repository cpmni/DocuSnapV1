Scan Finder — User Guide
User Guide

Use this page on your first day. It gets you from a pile of scans to one tidy, filed document.

Quick start

Two folders — keep them apart

Folder A is where filed documents end up. You choose it in step 1.
Folder B is where your fresh scans wait to be brought in (step 2).
Never scan into folder A.

  1. Create your login and answer the setup questions. You're the admin. The one that matters: where filed documents go — that's folder A. Don't point it at a folder that already holds scans. You'll know it worked when the Home screen appears.
  2. Scan one of each document into folder B. Away from the computer: pick one clean, flat, typical copy of each document you get often — start with your five biggest senders. One document per file. You'll know it worked when folder B holds one file per document.
  3. Teach each one. Click Teach (the buttons down the left). Choose a scan from folder B. Say what kind of document it is. Point out each detail it asks for: draw a box round the value; if a printed label sits beside it (“Invoice No:”) box that too; no label — the company name at the top — box the name on its own. Click Done, and repeat for each sender. You'll know it worked when the taught document is filed straight away, in folder A.
  4. Bring in the rest. Click Import → choose folder B → Process Documents. Scan Finder makes its own copy of each scan to read — your originals stay in folder B until you file them. A big pile is long enough to make a tea. You'll know it worked when the results table shows “Ready to file” or “Confirm to file” beside each one.
  5. Check what it wasn't sure about. Click Review — the number is how many are waiting. For a sender you taught, the details are already filled in; fix anything wrong by clicking the detail and typing over it. Confirm & File files the one you're looking at. File All Ready files only the rows marked Ready and leaves the rest. A filed document can always be sent back from Search. You'll know it worked when the number drops by one each time.
  6. Let it take over. Keep confirming. After enough correct ones from a sender, it starts filing that sender's documents without asking. Home shows “filed by itself” — click it to check them. Wrong one? Open it and click Put back. You'll know it worked when the count beside a sender's name reads “files by itself”.
  7. Find anything later. Click Search → type anything you remember → open it, or Show in folder. Still waiting in Review? Tick Include unconfirmed. You'll know it worked when the document opens.
How you know it all worked

Open folder A in Windows Explorer. You'll see it sorted into Company / Year / Month, with one neatly-named file for each document.

Want more detail on any step? Teach your documents, Import a batch and Check what it wasn't sure about each walk through one part slowly.
