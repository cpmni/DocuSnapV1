Scan Finder — User Guide
User Guide

Use this page on your first day with Scan Finder.

Quick start

This page takes you from a pile of scanned documents to a set of neatly filed, correctly named files. There are seven steps. You can read it in a few minutes, and you may find it easiest to follow with Scan Finder open beside you.

You will use two folders

It helps to decide these before you begin, and to keep them separate.

  • Folder A — your filing cabinet. This is where Scan Finder places finished, filed documents. You choose it during setup, in step 1.
  • Folder B — your in-tray. This is where fresh scans wait until you bring them in. You create it yourself, in step 2.

Keep them apart, and never scan directly into Folder A. Scanning into your filing cabinet would mix unread scans in with documents that are already filed.

  1. Create your login and complete the setup questions.

    The first time you open Scan Finder, you create an administrator login and answer a few setup questions. The most important asks where your filed documents should be kept: this is Folder A. Choose an empty folder, or create a new one for the purpose, rather than a folder that already contains scans. When you finish, the Home screen opens.

  2. Scan one example of each document into Folder B.

    Away from the computer, gather one clean, flat, typical copy of each kind of document you receive regularly. Begin with your five largest suppliers rather than trying to cover everyone at once. Scan each example into Folder B, saving one document to each file. These examples are what you will teach Scan Finder in the next step.

  3. Teach each example.

    On the Home screen, open Teach from the buttons on the left. Choose one of the scans in Folder B and tell Scan Finder what kind of document it is. It then asks you to point out each important detail in turn. For each one, you draw a box around the value on the page — the invoice number, the date, the total — and Scan Finder reads it back so you can check it. It finds the printed label beside each value for you (such as “Invoice No:”) and uses that label to locate the same detail on the supplier's future documents. When you click Done, Scan Finder files that document and remembers the layout, so it can read the rest of that supplier's documents by itself. Repeat for each example you scanned.

  4. Import the remaining scans.

    Open Import, choose Folder B, and click Process Documents. Scan Finder makes its own working copy of every scan and reads it; your original files stay in Folder B until you file them. A large batch may take several minutes. When it finishes, a results table lists each document as either Ready to file or Confirm to file.

  5. Check the documents it wasn't certain about.

    Open Review; the number beside it is how many documents are waiting. For any supplier you have taught, the details are already filled in — check them, and correct anything wrong by clicking the detail and typing over it. Confirm & File files the document you are looking at, and File All Ready files only the documents already marked Ready, leaving the rest for you. Nothing here is permanent: a filed document can always be sent back from Search.

  6. Let Scan Finder take over the routine filing.

    As you confirm correct documents from a supplier, Scan Finder grows more confident about it. After enough correct confirmations, it begins filing that supplier's documents without asking, and the Home screen shows how many it has filed on its own. Click that figure at any time to review them. If one is wrong, open it and click Put back to return it to Review.

  7. Find any document later.

    Open Search and type anything you remember — a company name, a reference number, part of a date. Open the document from the results, or click Show in folder to see where it was filed. If a document is still waiting in Review rather than filed, tick Include unconfirmed to include it in the results.

Seeing the result

To see everything Scan Finder has done, open Folder A in Windows Explorer. Your documents are sorted into folders by Company, then Year, then Month, and each file is clearly named with its type, date and reference number.
