Scan Finder — User Guide
User Guide

Use this page when you want to see the files themselves — or change how they're named.

Where things go

When you confirm a document, Scan Finder saves a tidy, clearly-named copy in your output folder. This page shows the layout, what happens to the original scan, and how to change the naming if you'd like it different.

The folder layout

Open the output folder any time from the Home screen's Output folder card. Everything in it is a normal PDF — you can copy, email or back it up like any other file.

What happens to the original scan

Nothing is deleted. When you import a folder, Scan Finder makes its own working copy of each scan; once a document is filed, the original is moved into a Processed folder so you can't accidentally import it twice. If you'd rather keep originals somewhere else — or not keep them at all once the filed copy exists — that's the Keep original scans after filing choice in Settings → Files & filing.

Change how documents are named and foldered

The layout above is only the default. In Settings → Files & filing, two simple builders control it — click the building blocks you want and a live preview shows the result.

  • Building blocks — Document Issuer, Year, Month, Type, Date and Reference.
  • A “/” starts a new folder level — Document Issuer / Year / Month makes three nested folders.
  • Duplicates — if the same document is filed twice, the second copy gets a label you choose (DUPLICATE, COPY, a number…) on the same tab.

How you know it worked: change something, watch the preview, and file one document — it lands exactly where the preview said.

The backup file

Your setup — document types, folders, naming, and everything Scan Finder has learned — can be saved to one password-protected file from Settings → Advanced → Backup & Restore. The Home screen's Backup card shows when you last did it. The backup does not contain the filed documents themselves; those are ordinary files in your output folder and belong in your normal file backups.

Filing is never final

A filed document can always be brought back: find it in Search and click Send back to Review. It stays filed until you re-confirm it.
