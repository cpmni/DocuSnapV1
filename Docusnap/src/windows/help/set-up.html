Scan Finder — User Guide
User Guide

Use this page the first time you open Scan Finder.

Set up

Sign in

The first time it opens, you create your own login — you become the admin. Keep the password somewhere safe; you'll need it each time. Later you can add other people, each with their own login and role, in Settings.

The setup questions

A short welcome, then a few quick questions. The one that matters:

Where do filed documents go?

Choose the folder where Scan Finder should keep your tidy, filed copies — folder A. Pick an empty folder, or make a new one. Don't point it at a folder that already holds your scans.

You can skip the rest and change everything later in Settings. When you're done, the Home screen appears.

The tour and a practice run

After setup, a short welcome tour points out the main parts of the screen. You can reopen it any time from your account menu (top right) → Show welcome tour.

Next to it is Try a practice run — a safe sandbox that walks you through the whole method on made-up documents: teach one by pointing out its details, import a small batch, and correct a detail before filing. Nothing you do there touches your real files or what Scan Finder has learned. It's the best five minutes you can spend before your first real batch.

The home screen

This is where you start each time. Down the left is the nav rail — the buttons you'll use most:

  • Home — this dashboard.
  • Import — bring in a folder of scans.
  • Review — check anything it wasn't sure about. The number is how many are waiting.
  • Teach — show it a new document so it learns that sender.
  • Search — find a filed document.
  • Settings — every option (admin only).

The middle of the screen shows cards: where your files go, storage, backup, recent activity, and — once you're an admin with things to export — Export data. If a newer version exists, a banner appears at the top; it installs the next time you restart.

Top right: the ? button turns on help mode (click it, then click any control for a one-line explanation), and your account menu holds Change password, Switch theme, User Guide…, the welcome tour, the practice run, About and Sign out. The Local only badge is a reminder: nothing leaves this PC.

What's next

Before your first big batch, teach one of each document you get regularly. It's what makes Scan Finder file the rest for you.
