### 1. ISSUER positional-read DROP — `engine.py`, kill switch `IDENTITY_POSITIONAL_DROP`
The fix from the 07-15 EVENING handover, built + **narrowed after an Oracle SEND BACK.** A swept position-
only issuer teach made SuperStore invoices read ANOTHER supplier's issuer POSITION → junk ("Item"/"Ship
To:"). The drop fires at the resolved-supplier seam and removes an identity-field read whose method is a

"anchor_registration")`. The first draft dropped ANY non-located anchor read and regressed 2 shipped tests
(`test_supplier_name_precedence`, `test_supplier_identity_stability`); Oracle sent it back, the predicate
was narrowed to `anchor_registration` only, and both tests now pass **unedited**. `_identity_key_for_type`

(every non-positional method KEPT; kill switch → byte-identical; None/no-key no-ops). **ALL PASS.**

### 2. Text-first issuer GRADUATION — `engine.py`, kill switch `TEMPLATE_IDENTITY_GRADUATE`

### 3. Date space/noise tolerance — `validator.py` + JS twins, **SALVAGE tier only**
OCR split a date ("1 5/06/2026", "2_ 2/4/26"); the strict parser then rejected it. `_date_preclean` joins
digit-runs split by whitespace and collapses separator whitespace — **but only at the SALVAGE tier**
(`salvage_date_detail`), NEVER in `parse_date`. Oracle's load-bearing condition: precleaning `parse_date`
would let a cleaned date clear the 94 clean-date tier and AUTO-FILE; salvage tier caps at 80, double-held

parsers kept in lockstep: `validator._date_preclean`, `review/renderer.js _datePreclean`,
`filing/handler.js _datePreclean`. Tests: `test_date_preclean.py` + updated `test_date_salvage.py`. PASS.

## TEACH STRAIGHTEN — the coordinate design (built + verified)

**Model: store-raw** (eric's design). The user draws boxes on the STRAIGHTENED display; boxes are stored
CANONICALLY in the RAW page frame so `doCommit → saveTemplateMapping` registers to the raw scan
**byte-identical to a non-straightened teach**. Only the on-screen overlay + a label re-read forward-
transform. Reuses the Review mechanism (`get-page-deskew` → `{angle, image}`) and the **proven**
`AnchorLabel.deskewedNormToRaw` primitive (R(+angle) straightened→raw; marker-pixel round-trip already
tested in `test_anchor_label.js`).

Why store-raw (not display-frame): `cropB64` reads `state.img` (the straightened image) with display-frame
boxes, so OCR is naturally correct on the level page — and because boxes are canonical RAW, **toggling
straighten on/off is trivially safe** (the overlay just forward-transforms with the current angle; nothing
to remap). `doCommit` is untouched.

Touch points (all in `src/windows/teach/renderer.js`):
- `state.rawImg / deskewImg / deskewImgAngle / deskewAngle` — added.
- `_teachBackBox(display→raw, on STORE)` / `_teachFwdBox(raw→display, overlay+reread)` — identity when
  `angle==0` (straighten off ⇒ byte-identical to today). Null-safe.
- `toggleTeachDeskew(forceOn)` — fetches the deskew render once (cached), swaps `state.img`, toggles the
  button `.active`. Guarded by `_teachDeskewBusy || _teachReadBusy || drag`.
- `startRegionStep` — sets `state.rawImg` after load and calls `toggleTeachDeskew(true)` **ON BY DEFAULT**
  (once per doc; silent no-op on an already-straight page).
- `store()` + `captureAnchor()` — back-transform the drawn box + anchor to RAW.
- `redetectAnchor()` — forward-transform `r.target` (raw) for the re-read crop, back-transform the label.
- `redrawCanvas()` — forward-transform the stored raw boxes for the overlay.
- `bindCanvas()` — wires `#tz-deskew`.

**Race guard:** a straighten toggle could race an in-flight OCR read (draw in frame A, canonicalize in
frame B). Two guards: each drawn box is tagged with `_ang` (the angle of the frame it was drawn in) and
`_teachBackBox` prefers it; and `_teachReadBusy` blocks the toggle during any read (readBack / captureAnchor
/ redetectAnchor). The manual-input path (OCR failed → user types) is covered by `_ang` on both the value
and label boxes.

**Verification:** standalone composition check (scratchpad) — a box drawn at display (0.62, 0.14) with a
2.4° skew stores raw (0.64051, 0.14593) [correctly offset], forward↔back round-trip error 1.1e-16, and
angle-0 is exact identity. `AnchorLabel.deskewedNormToRaw` itself is already unit-tested. `node -c` clean.
HTML button `#tz-deskew` (∞ icon, `data-help-key="teach-straighten"`) + `.zoombar button.active` style.

## DEFERRED — the SAME Straighten in the Template Manager (Settings → Templates `#tpl-dock`)

Requested this session ("straighten must be on by default in the teach wizard **and template manager**").
**NOT built** — it is not a clean port of the teach code, because of a real gotcha:

- The Template Manager displays via an **`<img>` (`tplImg`)** + an overlay canvas (not a canvas
  `drawImage`), so straightening means swapping `tplImg.src` to the deskewed data-uri and keeping the raw
  uri to swap back. `naturalWidth` is unchanged (expand=False) → overlay dims stay valid.
- **THE GOTCHA:** `checkAllMappingsTrack()` (`settings/renderer.js` ~line 2080, the "Show where it reads"
  diagnostic) builds a canvas from `tplImg` at `naturalWidth` and calls `test-template-mapping →
  resolve_geometry`, which resolves the saved (RAW-frame) mappings **against RAW pixels.** If `tplImg` has
  been swapped to the straightened render, the resolver runs on straightened pixels while the mappings are
  raw → it **silently mis-resolves.** The straighten build MUST keep that diagnostic reading the RAW image
  (hold a separate raw source ref, or force-unstraighten for the resolve).

Implementation sketch (a focused next build): add a straighten button to the tpl viewer toolbar; on sample
load fetch `get-page-deskew`, cache `{rawSrc, deskewSrc, angle}`, default ON; swap `tplImg.src`; in the
overlay draw forward-transform saved-mapping + draft boxes with the current angle; back-transform
`tplDraftAnchor/tplDraftTarget` to RAW on save; the OCR read-back crop (~line 1828) already reads `tplImg`
so a straightened swap makes it read level text; **pin `checkAllMappingsTrack` to the raw source.** Reuse
`AnchorLabel.deskewedNormToRaw` exactly as teach does. Add a coordinate round-trip check like the teach one.

I chose to defer rather than rush a coordinate feature whose failure mode is **silent mis-training** — the
exact class the project's philosophy warns against. The teach wizard is the primary training surface and
now has it.
