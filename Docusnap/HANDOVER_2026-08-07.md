## (B) Credit-note-typed-Invoice — THREE distinct causes, one owner toggle

All three are **type-changing** paths (type drives the filing folder AND the field set), so all default
OFF. The owner toggle `heading_absent_reread` bridges **three env flags** via `handler.js _reconcileEnv`.

**Cause #1 — `66c526a` + `4026222`: rung-3 absent-title pixel re-read (`HEADING_ABSENT_REREAD`).**
- **Root cause (proven):** the full-page `--dpi 300` PSM-3 pass **DROPS an oversized centred TITLE
  entirely** (Castellan 'CREDIT NOTE': dropped from full-page PSM-3 AND the PSM-6 supp merge; it reads at
  conf 96 WITHOUT the hint). The title therefore never reaches word geometry, so rung 2's
  `find_prominent_heading_band` is **blind by construction**. Type detection then sees only the body line
  "Credit against invoice …" and types Invoice.
- **Fix (oscar):** `ocr/heading_reread.py` — a NumPy **PIXEL** prominence pre-gate (NO OCR) finds the
  banner-height top-band ink run left UNREAD by the full-page pass, then a **TIGHT single-pass band
  re-read** recovers the title (a loose band re-garbles — proven, so the pre-gate returns tight bounds).
  Adoption via the SAME `detect_fn` + trusted-heading contract as rungs 1/2 (heading=True AND conf≥70) —
  **no new matcher**. A rung-3 SIBLING reusing the Oracle-signed rung-2 machinery, deliberately NOT a
  `reconstruct_page_text` change, to keep the fix off the core keyword-text path.
- **Honestly inert** on a cached reprocess / born-digital (needs fresh page-0 geometry).
- **Oracle SIGN-OFF-W/COND, opt-in:** C1 default-OFF + toggle (rung-3's input is enriched for content the
  main OCR rejected → wider FP surface; the Castellan heal is owner-watched because the harness can't
  bit-reproduce the `--dpi` drop) · **C2 OWNER-WATCH: a recovered type starts ungraduated at the 100
  floor — watch `(Castellan, credit_note)` graduating to 95** · C3 the field-set note · C4 scorer
  `HEAL_RE` counts "Banner heading recovered".
- **Corpus type-lane gate (cold, OFF vs ON, 221/224):** type **+1 a REAL heal** (Silverbeck
  sales_order_0061 recovered its dropped "SALES ORDER" title — proves rung-3 generalises beyond credit
  notes), **ZERO mis-type introduced**, every other lane byte-identical. The one collateral (Silverbeck
  total −1) is a correct type→field-set consequence and is pinned **WON'T-FIX-in-rung-3** (Oracle C3).
- Also in `4026222`: the scorer now SKIPS corpus files missing on disk (ENOENT was crashing the gate).

**Cause #2 — `2a9a556`: wide-spaced title gap-collapse (`HEADING_TITLE_GAP_COLLAPSE`, keyword.py).**
A letter-TRACKED title reconstructs with a ≥`COLUMN_BREAK_MIN` intra-title gap (`'CREDIT    NOTE'`), so the
column-aware heading test splits it into two columns and the title scores as a mere MENTION (Credit Note
4.7 vs 9.3) → mis-type. **Fix (herald):** collapse whitespace **ONLY inside the matched type-phrase SPAN**
before the column split — span-bounded, so an intra-title gap cannot split while genuine column breaks
OUTSIDE the phrase are preserved.

**Cause #3 — `2a9a556`: reprocess heading geometry (`REPROCESS_HEADING_GEOM`, process_docs.py).**
A cached reprocess never builds page-0 geometry, so the heading rungs are inert — one bounded page-0 pass
when there is no trusted heading.
