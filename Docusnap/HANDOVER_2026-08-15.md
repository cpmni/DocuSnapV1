**Gate (`database/modules/trust.js`, `1d1cdab`):**
- `critfield_corrob_floor_relax` (**G**) — a sub-88 ref/date clears the 88 floor iff `_corrobLicensed(corroboration)` AND `valueMatchesShape(scope dominant shape)`. `corroboration` added to the critfield SELECT only when armed. Nested under `corroboration_autofile`.

**Extraction (`python_backend/extraction/engine.py`, `cb69795`):** one gated `_resolve_corroborated_notes(results, field_defs, corrob, matched_tmpl)`, wired as **`_d4`** into the existing `_d1|_d2|_d3` recompute guard (engine.py ~8860) — **the key placement**: a cleared note there ALSO loses its `overall_confidence` penalty, so the doc clears the trust floor on import/reprocess. A stored-row clear CANNOT do this (the penalty is baked at extraction time) — which is why the live 84/72-conf docs need a reprocess, not just the remediation script.
- **A** `TEMPLATE_IDENTITY_CORROB_NOTE_SHED` — geometry-free twin of the G-FUZZY shed: sheds the FILL note iff licensed + graduated dominant issuer + value == issuer; method→`template_identity_corroborated`@85, value fixed.
- **B** `REF_DOMINANT_FORMAT_NOTE_DEMOTE` — drop the 1/I note + strip `_rawwitness` + clear a vacuous/1-confusable `corrected_to` iff `code_prefix(value)` == the scope's ≥0.90-dominant learned prefix (`lookup_prefix`).
- **C** `RECON_SHADOW_ATTRIB_NOTE_DEMOTE` — drop the shadow-attribution note iff licensed total + a penny-exact standard-VAT (0.20/0.05) tie to a separately-read, sign-agreeing operand. **Total value NEVER changed; no confidence change** (#464 rule).
- **D** `SNAP_CONFUSABLE_CLEAN_AUTOFILE` — adopt a single-canonical (`len(known)==1`) confirmed constant when the value is a single-confusable of it AND an independent supplier_hints family carries it. Symbol→digit map excludes `/` `\`.
- **E** `NAME_CORROB_SUGGESTION_ADOPT` — adopt a Stage-4.5 suggestion on a NON-identity field iff == the scope's dominant confirmed literal (share≥0.9, n≥5, from `confirmed_counts_index`) AND the page's own keyword read == the suggestion. supplier_name excluded.
- Shared `_corrob_licensed` mirrors trust.js; pinned cross-language in `test_corroboration_emit.py` (page-family set read from the JS source). New `test_corrob_note_resolve.py` = 20 pins (heal + fail-closed per class).
