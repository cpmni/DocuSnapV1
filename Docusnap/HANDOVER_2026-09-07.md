## 6. Traps learned today
- **`git add` refuses `src/modules/templates/…`** — a `.gitignore` `templates/` pattern shadows it; the file IS tracked;
  use `git add -f`.
- The realdoc harness's `run_*.log` holds the HARNESS output only — engine log lines (compose/abstain/fit counts) are not
  there; count effects via `RR_CONSENSUS` diffs (`scratchpad diff_consensus.py`) or a single-doc trace
  (`TESTING/_measure/teach_import_20260907/trace_single_doc.js`; `NO_TRACE=1` keeps the OCR pools armed — `--trace`
  forces serial).
- A realdoc arm running = `node_modules/electron/dist/electron.exe` busy → `npm run build` must wait (EBUSY).
- Scratchpad Node scripts must `require()` better-sqlite3 by absolute repo path; `APPDATA` can be empty under
  electron-as-node — use the absolute DB path.
- A patch-script anchor that spans comment lines fails when the source was read with comments stripped — print the exact
  lines (`sed -n`) before writing the anchor.
- The auto-mode Bash classifier can time out; read-only Grep/Read still work — reach for them.
